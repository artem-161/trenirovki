# Тренировки

PWA для учёта тренировок: свои упражнения с подписью и группой, запись подходов (вес × повторения, повторения, время, дистанция, просто количество), история, графики прогресса и календарь.

Без сборки и зависимостей: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`.

## Данные
Хранятся в `localStorage` телефона (ключ `trenirovki.v1`), у каждого человека свои. Резервная копия — вкладка «Ещё» → «Сохранить копию» (файл .json, можно положить в «Файлы»/iCloud), восстановление — оттуда же.

## Локальный запуск
```bash
python3 -m http.server 8765
```
Открыть http://localhost:8765

## Публикация
Нужен любой статический хостинг с HTTPS (GitHub Pages, Netlify, Cloudflare Pages). Залить содержимое папки целиком. На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».

## Обновления
После изменения файлов увеличь `VERSION` в `sw.js`. На телефоне новая версия подхватывается со второго запуска приложения (первый запуск берёт кэш и в фоне скачивает обновление).
